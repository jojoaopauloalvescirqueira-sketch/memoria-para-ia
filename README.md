# Memória para IA

Pacote local do plugin AI Memory 3.1.1 para memória entre sessões e agentes.

Consulte [LEIA PRIMEIRO.md](LEIA%20PRIMEIRO.md) para a organização da cópia e [plugin/README.md](plugin/README.md) para requisitos, funcionamento e licença.

Este repositório preserva uma configuração específica de Mac, com caminhos absolutos em `plugin/mcp.json`. O binário, o servidor, as credenciais e o banco de memórias não estão incluídos. A publicação não instala nem ativa a integração.
